# 🎴 UI Card Animation (HTML, CSS & JavaScript)

A visually engaging and dynamic **UI Card Animation project** built using **HTML, CSS, and Vanilla JavaScript with GSAP**.

This project features **full-screen animated cards** that transition smoothly with **auto-play slider functionality**, delivering a premium and interactive user experience.

---

## 🧱 Project Structure

```bash
ui-card-animation/
│
├── index.html         # Main structure and layout
├── styles.css         # Styling, layout & animations
├── main.js            # Logic, animations & transitions (GSAP)
├── LICENSE
└── README.md          # Project documentation
```

---

## ✨ Features

### 🎴 Animated Card Slider

* Full-screen dynamic card transitions
* Smooth sliding and scaling animations
* Auto-loop animation with timeline control

### 🎯 Interactive Experience

* Navigation arrows for manual control
* Progress indicator animation
* Slide number tracking system

### 🎨 Modern UI Design

* Clean and minimal layout
* Overlay text animations (title, description)
* Responsive typography using Google Fonts

### ⚡ Performance Optimized

* Lightweight structure
* Powered by **Vanilla JavaScript + GSAP**
* Preloaded images for smooth rendering

| Technology                  | Role                              |

## 📌 Purpose of This Project

This project is built to:

* Practice **advanced animations using GSAP**
* Learn **dynamic UI transitions**
* Improve **frontend design creativity**
* Understand **animation sequencing & timing**
* Build **real-world interactive UI components**

> ⚠️ This is a frontend-only project created for learning and UI experimentation.
